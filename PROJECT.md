# Acacias Apart

## Alcance confirmado

Landing estática de Acacias Apart, La Paz, Entre Ríos, destinada a consultas por WhatsApp y correo. Astro, TypeScript estricto, pnpm, Tailwind 4, fotografías reales y PhotoSwipe. Sin backend, CMS, reservas, pagos ni tracking. La publicación definitiva será en Wiroos; esta iteración publica el código en el repositorio GitHub indicado y prepara Vercel sin cambiar DNS ni el sitio en Wiroos.

El usuario autorizó implementar el plan el 31/10/2026 y aprobó expresamente la dirección visual H2 antes de extenderla. Confirmó WhatsApp y vigencia de los datos comerciales publicados; proporcionó el mapa; indicó retirar aviso COVID y Safe Travels, y usar siempre el año actual. Registro: docs/approvals.json.
